Know what is on the network, at any scale

Fast live-host sweeps built on nmap host discovery, designed for large internal address space.

  • Sweep CIDR ranges, IP ranges, lists and hostnames in nmap target syntax, with no cap on range size
  • New live hosts are appended to a named target group; nothing is removed, so repeated sweeps build lasting coverage
  • Tunable packet rate, timing template, retries and per-host timeout, with live progress
  • Passive OS and device hints from reply TTL and MAC vendor, plus reverse-DNS names
  • A guard flags sweeps where an implausible share of a range answers (proxy-ARP or RST-everything devices)
Read the deep dive

Audit exposed services and legacy protocols

A read-only audit of 130+ legacy-protocol and exposed-service checks, built for internal infrastructure as well as the perimeter.

  • Ten module groups: plaintext protocols, weak TLS, Windows/SMB/Active Directory, remote access, network infrastructure, cloud metadata, containers, databases, IoT messaging, and dev tools & admin panels
  • Targets as IPs, hostnames or IPv4 CIDRs with no CIDR-size cap; tune concurrency and per-probe timeout
  • Every scan belongs to a named group, so repeated audits accumulate coverage over time
  • Each finding carries a severity and concrete remediation guidance
Read the deep dive

Find exposed industrial and IoT services safely

A dedicated OT/IoT Exposure scanner covering 64 industrial, building-automation, energy and IoT protocols.

  • Protocols include Modbus/TCP, Siemens S7comm, DNP3, EtherNet/IP, IEC 60870-5-104, OPC UA, BACnet/IP, PROFINET, MQTT and more
  • Every hit is confirmed with a single safe, read-only protocol handshake, never a write, start, stop, program or login
  • Only stock, non-intrusive nmap scripts are used; an optional UDP pass and per-host timeout keep sweeps in check
  • Severity reflects impact of exposure, with remediation focused on segmentation and access restriction
Read the deep dive

Layered vulnerability scanning with a plugin chain

The New Scan engine combines core web checks with an optional chain of 20+ best-in-class open-source scanners.

  • Core web checks: headers, TLS, technology detection, CORS, HTTP methods, open redirect and XSS
  • Optional plugin chain including nuclei, httpx, subfinder, naabu, dalfox, sqlmap, retire.js and an OpenAPI spec audit
  • Normal, Deep and Comprehensive presets, or choose exactly which checks run
  • Findings from several tools for the same issue are merged into one corroborated entry
